# CrisisGrid

> A real-time crisis management simulation built with React and TypeScript.

## Overview

CrisisGrid is an interactive crisis response simulation where players manage emergency incidents across a city by dispatching limited resources, prioritizing events, and maintaining public trust.

The goal of this project is to explore modern frontend architecture while building a realistic simulation with scalable design principles.

## Tech Stack

- React
- TypeScript
- Vite
